## API semantics

```php
$result = app(\App\Support\Reference\FittingDimensions::class)
    ->lookup('ELBOW', '90LR', '1/2');
// status AVAILABLE; row.mm = 38; row.dimension = CENTRE_TO_END;
// row.symbol = A; row.sourceTable = Table 6.1-1;
// source includes standard edition, version and source verification metadata.

$result = app(\App\Services\PipingClassBody::class)
    ->fittingDimensionForItem($item);
```

Every result contains `status`, `reason`, `row`, `source`. Unsupported or incomplete requests return `UNAVAILABLE`, a reason code, and a null row, never zero or an interpolated dimension. Missing/corrupt reference files raise exceptions rather than being disguised as missing engineering coverage. A whole pack is validated before its index is cached.

Supported: LR90, explicitly LR45, and caps. Exact aliases `90LR` and `45LR` map to the corresponding long-radius definitions. The existing template qualifier `45` alone does **not** prove long radius and returns `RADIUS_UNSPECIFIED`. Short-radius/180-degree elbows, tees and reducing/two-size fittings remain outside this dataset. Known pipe sizes beyond the tabulated fitting range return `SIZE_NOT_TABULATED`, not physical invalidity.

The PMS consumer requires B16.9 (optionally `ASME` prefix and `-2018` edition), an explicit BW end, and consistent NPS/DN. Unsupported edition, incompatible/missing ends and conflicting sizes are separate refusal reasons. A bare standard code uses the available pack edition, which remains visible in provenance. It does not parse arbitrary free-form standard citations or guess a standard from a component type.

Geometry availability is **not** pressure adequacy, class permission, verification of the entire PMS, a physical model dimension, an MTO cut length, or independent standards certification. The source pack's `verified` field is carried as source metadata, not newly independently verified here. The elbow centre-to-end dimension remains distinct from cap length; neither overwrites a model's `length_mm`. No schedule-derived rating is invented.
