## گزینه‌ها و پیامدها

نمایندهٔ جدا، تأیید فقط فرستنده، مسدودسازی عملیات و دید فقط همان شرکت پیشنهاد ولی انتخاب نشدند؛ پنهانی جایگزین یا دوباره پرسیده نشوند. اشتراک تاریخچه عمدی و اعلام‌شده، نه افشای پیش‌نویس خصوصی. مرجع آزاد اصلاح معتبر ITP یا lineage کالا نیست. تأیید تحقق نه دریافت، پذیرش/نتیجهٔ بازرسی، release یا اجازهٔ کار؛ نه اختیار/نوشتن MR/PO/MTO/موجودی یا نقش پیش‌فرض. تمامیت runtime نه مصونیت DDL ممتاز یا امضای حقوقی.

پنج انتخاب ADR-042، فقط ابطال ADR-043، دریافت/PDF در ADR-044 و مرز ADR-041 محفوظ؛ فقط تعویق پیش‌نیاز گیرنده جایگزین. بایگانی مرجع، اعلان قدیمی، فیلتر فقط‌خواندنی و تاریخچهٔ خصوصی محفوظ. جایگزینی/صدور مجدد/تغییر زمان/ارسال/پیوست و PDF پیش‌نیاز معوق؛ پیوند ITP/سیاست مستقل آمادگی پیشنهاد، نه فعال‌شده.
