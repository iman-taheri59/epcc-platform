# ADR-044 — تأیید دریافت شرکت برای اصل و ابطال

> **الحاقیهٔ پیش‌نیاز — ۲۰۲۶-۱۰-۲۰:** [ADR-045](ADR-045-INSPECTION-NOTIFICATION-PREREQUISITES-FA.md) / [راهنما](INSPECTION-NOTIFICATION-PREREQUISITES-FA.md): مدیریت خوانندهٔ همان گیرنده، گزارش صادرکنندهٔ جاری فرستنده، تأیید/رد گیرندهٔ اعلام‌کننده، دید تاریخچهٔ نسخه‌دار برای همهٔ خوانندگان اصل صریحاً تصویب و اجرا شد. نه gate خودکار یا تغییر اصل/PDF/تاریخچهٔ خصوصی. فقط تعویق پیش‌نیاز جایگزین؛ انتخاب‌های قبلی محفوظ.۸۱/۱۲۹۰ + ارتقای جدا۱/۵ موفق؛ نه full-suite/استقرار.

## تصمیم‌های تأییدشده

انتخاب `next_scope=recipient_acknowledgment`؛ `ack_authority=any_authorized_company_reader`؛ `ack_target=issue_and_cancellation_separate`؛ `ack_visibility=all_authorized_notice_readers`؛ `ack_pdf_scope=detail_and_current_pdf`.

هر خوانندهٔ مجاز فعلیِ شرکت گیرندهٔ انتخاب‌شده، صریحاً **دریافت شرکت** را ثبت می‌کند؛ نه فقط خودش و بدون معرفی جدا/نقش مدیر/صادرکننده/doc. این read-to-write فقط برای همین اقدام صریحاً تأیید شده است. اولین دریافت هر اعلان/شرکت/رویداد، یکتا و append-only؛ نه tracker بازکردن صفحه/دانلود یا تحویل مشاهده‌شده. بدون ویرایش/پس‌گرفتن/زمان دلخواه/یادداشت؛ شخص/نام شرکت/زمان از سرور، نه selector اختیار/انتساب client.

دریافت ISSUE فقط پیش از ابطال؛ دریافت CANCELLATION با پیوند ابطال دقیق. دریافت اصل حفظ و هیچ‌کدام معادل دیگری نیست؛ ابطال بدون دریافت اصل هم دریافت می‌شود. وضعیت جهانی ACKNOWLEDGED نداریم و state/version/متن/snapshot/گیرندگان/شمارهٔ اصل تغییر نمی‌کند. فرستنده از طرف شرکت دیگر نمی‌تواند اقدام کند؛ فرستندهٔ گیرنده فقط برای خودش. کنترل فعال‌بودن/عضویت/مشارکت/رشته/کیفیت/pack فعلی؛ بایگانی پروژه مانع ثبت تازه، بایگانی مرجع نه تفویض دسترسی و نه مانع دریافت مدرک محفوظ. doc module/read/issue برای دریافت گیرنده لازم یا تفویض نمی‌شود.

همهٔ خوانندگان مجاز اصل، شرکت/شخص/زمان ثبت‌شدهٔ همهٔ دریافت‌ها را می‌بینند؛ این دید بین گیرندگان صریحاً انتخاب شده، نه تاریخچهٔ خصوصی یا directory/مرجع/اطلاعات تجاری. جزئیات/PDF جاری شامل رکوردها؛ بعد از render دسترسی، ابطال و IDهای مرتب رویدادهای ثابت دوباره بررسی و در صورت تغییر۴۰۹/retry داده می‌شود. فایل قبلی پس‌گرفتنی نیست. تمامیت runtime برنامه/SQL نه رسید حقوقی/رمزنگاری/امضا یا مصونیت DDL است.

## گزینه‌ها / مرز

نمایندهٔ مستقل، دریافت شخصی، دید فرستنده+همان گیرنده و خروجی فقط جزئیات پیشنهاد ولی انتخاب نشدند؛ دوباره پرسیده یا پنهانی جایگزین نشوند. پنج انتخاب ADR-042، فقط ابطالِ ADR-043 و مرز ADR-041/MTO محفوظ. فقط تعویق دریافت محدود جایگزین شد. جایگزینی/صدور مجدد/تغییر زمان/undo، ارسال/outbox، امضا، حضور، پذیرش فنی/نتیجه/hold/release/ادامه معوق؛ نه اختیار عمومی read-to-write.

migration140000 رو‌به‌جلو با RLS اصل و migrationهای قبلی ثابت، بدون نقش پیش‌فرض/رویداد قدیمی فرضی. قفل مشترک پروژه، بررسی جاری SQL و رویداد یکتای ثابت؛ گیرنده UPDATE روی اصل فرستنده نمی‌خواهد. آزمون۶۱/۱۰۴۰ + ارتقای جدا۱/۵ موفق، PDF نهایی هم‌پوشان۱/۲۲ موفق؛ نه full-suite/CI جاری/تولید. پوشش، خطای fixture و اصلاح، مرز اعتماد و پیشنهادهای سیاست/قرارداد در راهنما است. commit/push/استقرار انجام نشد.
