## ادامهٔ تأییدشده

کاربر پس از تحویل فیلترها **`next_scope=filter_usability`** را انتخاب کرد: هماهنگی ورود تاریخ/ساعت فیلتر با کنترل‌های موجود و بررسی مرورگری فارسی/انگلیسی، بدون اختیار/گردش‌کار تازه. مجوز، schema/migration، سرویس/controller/query/parser و قواعد ابطال/جایگزینی/تأیید دریافت تغییر نکردند. تصمیم‌های فیلتر قبلی پذیرفته/اجراشده و گزینه‌های گردش‌کار جدید همچنان انتخاب‌نشده‌اند.

## استفاده

هر مرز **از / تا** اکنون تاریخ میلادی، ساعت با ثانیه، offset صریح UTC، نمایش مقدار دقیق و حالت ورود مستقیم دارد. ترتیب تاریخ یا ساعت۱۲ساعته در کنترل native ممکن است تابع locale مرورگر باشد، ولی متن ارسالی ثابت است: `YYYY-MM-DDTHH:MM:SS±HH:MM`، مثلاً `2026-10-25T23:30:45+03:30`. تبدیل شمسی، تبدیل به منطقهٔ مرورگر یا offset پیش‌فرض/حدسی انجام نمی‌شود. مقدار دقیق و پیش‌نمایش در صفحهٔ RTL چپ‌به‌راست و برچسب/راهنمای اختیاری/بدون‌اسکریپت ترجمه‌شده‌اند.

- برای حذف یک مرز **هر سه بخش** آن را خالی بگذارید. هر دو مرز می‌توانند خالی باشند یا فقط یکی پر شود؛ مقدار خالی query مانند قبل در parser سرور به‌معنای نبود مرز است.
- با ورود هر بخش، تکمیل هر سه لازم می‌شود. تغییر/پاک‌کردن ناقص، مقدار دقیق قبلی را حذف و ارسال را تا تکمیل یا پاک‌کردن کامل مسدود می‌کند؛ نه تاریخ ماندهٔ قبلی ارسال می‌شود، نه جست‌وجوی موردنظر ناخواسته بی‌مرز می‌شود. پیش‌نمایش «بدون مرز» را از «ناقص» تفکیک می‌کند.
- مرز پرشده offset صریح می‌خواهد؛ UTC برابر `+00:00` است، نه `-00:00`. ثانیه حفظ می‌شود؛ اگر کنترل native فقط ساعت/دقیقه بدهد، `:00` افزوده می‌شود. تاریخ میلادی/offset خراب در ورود مستقیم توسط helper رد می‌شود؛ اعتبارسنجی سرور برای همهٔ clientها و سال نرمال‌شده/ترتیب بازه مرجع نهایی است.
- تیک ورود مستقیم، helperها را غیرفعال و مقدار دقیق را قابل‌ویرایش می‌کند. خالی‌کردن عمدی آن مرز را حذف می‌کند. بازگشت به helper، اجزای مقدار معتبر را بدون تغییر تاریخ/ثانیه/offset بارگذاری می‌کند. بخش ناقص helper هنگام تعویض حالت، query پنهانِ دیگری نمی‌سازد.
- بدون جاوااسکریپت یا پشتیبانی native تاریخ/ساعت، helper مخفی و فیلد دقیقِ اختیاری قابل‌استفاده است؛ راهنمای ترجمه‌شده، حذف هر مرز را توضیح می‌دهد. مقدار مستقیم نامعتبر و مرز معکوس در **زمان مطلق** همان۴۲۲ سرور را می‌گیرند؛ مرزها خودکار جابه‌جا نمی‌شوند. برابری دو مرز همچنان جست‌وجوی لحظه و تماس مرزی هم‌پوشانی است. client اعتبارسنجی قطعیِ ترتیب UTC/سال نرمال‌شده را تکرار نمی‌کند.
- GET فقط نام‌های اصلی مرز را می‌فرستد؛ اجزای بی‌نام helper با POST پیش‌نویس مخلوط نمی‌شوند. اعمال/پاک‌کردن، لینک زبان/مرحله، scope، صفحهٔ۲۵تایی و آمار مجاز ثابت‌اند. انتخابگر مرجع فیلتر زمانی نمی‌شود؛ بازهٔ نامعلوم قدیمی فقط با وجود مرز زمانی کنار گذاشته و هرگز حدس زده نمی‌شود.

## مرز کامپوننت مشترک

`time-field.blade.php` پارامترهای داخلی نام/عنوان/اختیاری دارد؛ مصرف‌کنندهٔ ثبت/ویرایش به‌صورت پیش‌فرض شروع/پایان اجباری و payload قبلی `notification[activity_*_at]` را نگه می‌دارد. فیلتر صریحاً IDهای یکتای `filter-from` / `filter-to` و نام‌های `activity_from` / `activity_to` دارد. اسکریپت مشترک همه را یک‌بار با state مستقل در fieldset راه‌اندازی می‌کند؛ helper اختیاری فقط هنگام ورود یک بخش اجباری می‌شود و رفتار اجباری نوشتن باقی است. فیلتر، بازهٔ پیش‌نویس را پر یا عوض نمی‌کند.

## آزمون و شواهد

**۲۶ آزمون مرتبط PHP /۴۰۴ assertion موفق،۲۴٫۶۹۵ ثانیه، بدون skip**:۹ فیلتر فهرست (یک مورد تازهٔ قرارداد UI/DOM/فقط‌خواندنی)،۴ UI قبلی،۳ parser فیلتر و۱۰ ورودی. full-suite تکرار نشد؛۵۸/۶۴۰ قبلی تاریخی و غیرقابل‌جمع است. مورد تازه هر دو زبان، حالت خالی/مرز برابر، نام GET، اختیاری در برابر فیلد اجباری نوشتن، یکتایی ID و ثابت‌بودن رکورد پس از GET را می‌سنجد؛ موارد قبلی دسترسی/محرمانگی/query/صفحه‌بندی نیز اجرا شدند.

**Chromium واقعی با Playwright:۷ گروه سناریو /۱۴۷ بررسی موفق.** صفحات آزمایشیِ رندرشدهٔ جاری Laravel؛ فارسی/انگلیسی در Asia/Tehran و America/New_York، حالت بدون JS برای هر دو زبان و موبایل فارسی۳۹۰پیکسلی. پوشش خالی/ناقص/تکمیل/پاک‌کردن، یک‌مرزی/نقطه‌ای/عبور نیمه‌شب، UTC/offset و تاریخ نامعتبر، رفت‌وبرگشت مستقیم، تفکیک FormData/حفظ context/صفحه، لینک زبان/پاک‌کردن، جدایی پیش‌نویس/ویرایش، RTL/LTR و جاگیری کنترل موبایل. ارسال‌ها محلی capture و شبکه مسدود شد؛ نه مسیر HTTP احرازهویت‌شدهٔ زنده/تولید یا گواه popup تقویم native/همهٔ مرورگرها. رفتار GET سرور جدا با feature test بررسی شد. Safari/Firefox، بار/هم‌زمانی ادعا نمی‌شود. فایل دستورالعمل skill در مسیر نصب موجود نبود؛ Playwright/Chromium نصب‌شده مستقیم استفاده شد.

[شواهد](evidence/2026-10-20-inspection-notification-filter-ui/README.md): فرمان تکرار، HTML مصنوعی با CSRF جایگزین‌شده، خلاصه/لاگ مرورگر، تصویر موبایل، خروجی PHP، Pint تازه/lint/Blade/diff، hash و audit/خاموشی DB خصوصی. token واقعی یا دادهٔ تولید ثبت نشده است. PostgreSQL17 خصوصی با نقش `epcc` بدون superuser/bypassRLS، فقط Unix socket و FORCE RLS؛ بعد از بررسی خاموش شد. commit/push/استقرار انجام نشد.

## پیشنهاد / تعویق

کنترل native تابع مرورگر/locale است؛ مقدار canonical مسیر قابل‌اتکای بررسی و fallback می‌ماند. UI شمسی یا گسترش پشتیبانی مرورگر، طراحی/آزمون صریح می‌خواهد؛ نه تغییر ضمنی ذخیرهٔ میلادی/offset. پیشنهاد سنجش بار واقعی پیش از index جدید جست‌وجو ثابت است. چرخهٔ صادرشده، دریافت/acknowledgment، امضا/ارسال و قواعد Hold/release تصمیم جدا هستند؛ اختیار MTO/PO/MR یا دسترسی تاریخچه اضافه نشده است.
