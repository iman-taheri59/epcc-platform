# ADR-043 — ابطال مستقل نوتیفیکیشن بازرسی صادرشده

> **الحاقیهٔ پیش‌نیاز — ۲۰۲۶-۱۰-۲۰:** [ADR-045](ADR-045-INSPECTION-NOTIFICATION-PREREQUISITES-FA.md) / [راهنما](INSPECTION-NOTIFICATION-PREREQUISITES-FA.md): مدیریت خوانندهٔ همان گیرنده، گزارش صادرکنندهٔ جاری فرستنده، تأیید/رد گیرندهٔ اعلام‌کننده، دید تاریخچهٔ نسخه‌دار برای همهٔ خوانندگان اصل صریحاً تصویب و اجرا شد. نه gate خودکار یا تغییر اصل/PDF/تاریخچهٔ خصوصی. فقط تعویق پیش‌نیاز جایگزین؛ انتخاب‌های قبلی محفوظ.۸۱/۱۲۹۰ + ارتقای جدا۱/۵ موفق؛ نه full-suite/استقرار.

> **الحاقیهٔ جاری دریافت — ۲۰۲۶-۱۰-۲۰:** [ADR-044](ADR-044-INSPECTION-NOTIFICATION-ACKNOWLEDGMENT-FA.md) / [راهنما](INSPECTION-NOTIFICATION-ACKNOWLEDGMENT-FA.md). انتخاب صریح: هر خوانندهٔ مجازِ گیرنده نمایندهٔ همان شرکت؛ دریافت اصل فقط پیش از ابطال و دریافت ابطال دقیق، جدا و اولین/شرکت/رویداد ثابت؛ دید شرکت/شخص/زمان برای همهٔ خوانندگان اصل در جزئیات/PDF جاری. نه tracker خودکار، اختیار سند/صدور/موجودی/نتیجه یا افشای تاریخچهٔ خصوصی.۶۱/۱۰۴۰ + ارتقای جدا۱/۵ موفق؛ PDF هم‌پوشان۱/۲۲ موفق. فقط تعویق دریافت جایگزین؛ فقط ابطال/تعویق جایگزینی/ارسال/امضا ثابت. نه full-suite/CI/تولید.

## ثبت تصمیم

انتخاب `next_scope=issued_lifecycle` و سپس صریحاً `lifecycle_authority=current_issue_grant`، `lifecycle_transitions=cancel_only` و `lifecycle_visibility=status_reason_scoped_replacement`. این‌ها قطعی‌اند؛ از نام گزینهٔ دید، نقش خودکار یا قابلیت جایگزینی استنباط نشود.

مجوز جاری و صریح صدورِ همان شرکت برای ابطال نهایی مستقل استفاده می‌شود؛ دلیل اجباری و شخص/نام/زمان/آخرین تنظیم مجوز ثبت می‌شود. نه محدود به صادرکنندهٔ اصلی و نه انتصاب تازهٔ پیش‌فرض. متن/شماره/نسخه/snapshot/گیرندگان اصل ثابت و یک رویداد append-only با FORCE RLS اضافه می‌شود. وضعیت مؤثر CANCELLED محاسبه و raw ISSUED مدرک تاریخی صدور می‌ماند. بدون undo/برگشت به DRAFT؛ PDF تازه رویداد جاری را دارد و ابطال حین render،۴۰۹ و retry می‌خواهد.

خوانندگان مجاز اصل، از جمله گیرندگان انتخاب‌شده با scope/entitlement فعلی، وضعیت/دلیل/شخص/زمان را می‌بینند؛ نه تاریخچهٔ خصوصی، تفویض مرجع/PO یا نوشتن cross-company. آخرین مجوز پیمانکار اصلی و کنترل جاری پروژه/رشته/مشارکت/module/pack/فعال‌بودن ثابت؛ بایگانی پروژه مانع نوشتن است. پس‌گرفتن اعلان محفوظ، صلاحیت قدیمی مرجع/گیرنده برای صدور جدید نمی‌خواهد. وقت قدیمی بازهٔ نامعلوم می‌ماند.

## گزینه‌ها و پیامدها

فقط صادرکنندهٔ اصلی و انتصاب مستقل پیشنهاد ولی انتخاب نشدند. جایگزینی اتمیک و ابطال+جایگزینی پیشنهاد ولی انتخاب نشدند. دید فقط وضعیت برای گیرنده پیشنهاد ولی انتخاب نشد. شرط دید جایگزینِ آینده، دسترسی مستقل به آن است؛ اکنون اجرا نشده. پنج تصمیم ADR-042 و مرز ADR-041/MTO ثابت. فقط تعویق **ابطال** جایگزین شد؛ جایگزینی/تغییر زمان/صدور مجدد/تأیید دریافت/ارسال/امضا/ابطال نتیجه معوق‌اند.

دلیل عمداً به گیرندهٔ مجاز افشا می‌شود؛ پیش از ارسال هشدار لازم است. فایل دانلودشده پس گرفته نمی‌شود. integration مبتنی بر raw state باید رویداد را لحاظ کند؛ API خارجی تازه‌ای نداریم. guard برنامه/SQL تمامیت runtime مورداعتماد است، نه اثبات رمزنگاری/مصونیت DDL. migration130000 رو‌به‌جلو بدون backfill/مجوز پیش‌فرض؛ ارتقای پروژهٔ بایگانیِ دارای داده آزموده شد. آمار دقیق۵۹/۸۸۴ +۱/۵ نهایی و آزمون هم‌پوشان PDF۱/۲۲ در راهنما/شواهد است؛ نه ادعای موفقیت۹۰موردی/full-suite/تولید.
