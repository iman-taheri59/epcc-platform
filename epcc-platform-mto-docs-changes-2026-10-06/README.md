## اعمال در مخزن

۱. از نسخه‌های فعلی همین فایل‌ها در مخزن مقصد نسخهٔ پشتیبان بگیرید.
۲. محتوای این بسته را با حفظ مسیرهای نسبی در ریشهٔ مخزن `epcc-platform` کپی کنید.
۳. پیش از commit، تغییرات را با فایل‌های مخزن مقصد مقایسه و بازبینی کنید.

**هشدار:** این‌ها نسخهٔ کامل فایل‌ها هستند، نه diff خط‌به‌خط. چون محیط فعلی Git baseline یا remote نداشت، امکان مقایسه با نسخهٔ موجود در GitHub فراهم نبود؛ اگر مخزن مقصد تغییرات دیگری در این فایل‌ها دارد، آن‌ها را پیش از جایگزینی ادغام کنید.
